# Salary Dependency Manager — FastAPI

Веб-версія застосунку для керування посадами, чотирма рівнями оплати та формульними залежностями між ними. Backend реалізований на FastAPI, а інтерфейс працює через асинхронні AJAX-запити без перезавантаження сторінки.

## Можливості

- додавання та видалення посад;
- чотири рівні зарплати й бонусу для кожної посади;
- ручні значення для незалежних рівнів;
- формули на основі `S` (зарплата джерела) і `B` (бонус джерела);
- залежності між рівнями однієї або різних посад;
- автоматичний перерахунок ланцюжків залежностей;
- виявлення та заборона циклічних залежностей;
- збереження повного стану в CSV;
- безпечне завантаження CSV із перевіркою формату та версії;
- адаптивний веб-інтерфейс українською мовою;
- інтерактивна документація API у `/docs`.

## Запуск

Потрібен Python 3.10 або новіший.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Після запуску відкрийте:

- застосунок: <http://127.0.0.1:8000>
- Swagger UI: <http://127.0.0.1:8000/docs>

## Робота з правилами

1. Додайте всі потрібні посади.
2. Натисніть **Правила** біля потрібної посади.
3. Для незалежного рівня залиште **Без залежності** та введіть зарплату й бонус вручну.
4. Для залежного рівня виберіть посаду й рівень джерела, після чого введіть формули.
5. Натисніть **Зберегти правила** — усі залежні значення перерахуються автоматично.

Формули підтримують числа, `S`, `B`, дужки та оператори `+`, `-`, `*`, `/`. Використання `eval()` відсутнє: вираз обробляється через обмежене AST-дерево.

## CSV

Кнопка **Зберегти CSV** завантажує файл, який містить:

- службовий запис формату й версії;
- усі рівні посад та їхні поточні значення;
- джерела і формули, показані в редакторі;
- окремі записи активних залежностей.

Кнопка **Завантажити CSV** повністю замінює поточний стан лише після успішної перевірки всього файла. Сторонній файл, файл без службового маркера, неповна посада, невалідна формула або циклічна залежність відхиляються без втрати поточної роботи.

## API

| Метод | Шлях | Призначення |
|---|---|---|
| `GET` | `/api/state` | Отримати весь поточний стан |
| `POST` | `/api/positions` | Додати посаду |
| `DELETE` | `/api/positions/{name}` | Видалити посаду та пов’язані залежності |
| `PUT` | `/api/positions/{name}/rules` | Зберегти чотири правила та перерахувати значення |
| `GET` | `/api/export` | Завантажити повний CSV-знімок |
| `POST` | `/api/import` | Завантажити CSV-знімок у тілі запиту |

## Поточна модель зберігання

Робочий стан зберігається в пам’яті процесу FastAPI та є спільним для відкритої локальної сесії. Для перенесення стану між запусками використовуйте CSV. Для багатокористувацького публічного розгортання наступним кроком має бути окреме сховище або база даних.
